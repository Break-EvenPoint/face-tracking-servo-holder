# 구현 및 실험 결과

최종발표에서 얼굴 인식 처리 속도, 방향 추정 오차, 모터 응답 및 안정화 시간을 시험했다.

| 측정 항목 | 최종발표 결과 | 측정 내용 |
|---|---:|---|
| 얼굴 영상 처리 속도 | **22.23 FPS** | 약 10초 동안 223프레임 처리 |
| Yaw 추정 평균 절대오차 | **2.78°** | -40°부터 +40°까지 9개 각도 비교 |
| 처리부터 모터 반응 시작까지 지연 | **35ms** | 한 번의 응답 측정 사례 |
| 데드존 진입 평균 시간 | **1.54초** | 얼굴 위치 변경 후 10회 기록 |
| 데드존 진입 최대 시간 | **1.72초** | 위 10회 기록의 최대값 |
| 연속 동작 | **20분** | 발표 기록상 오류·연결 끊김 0회 |


위 Yaw 오차는 **얼굴 방향 추정 오차**이고, 서보모터의 실제 각도 추종 오차와는 구분한다. 35ms는 응답 지연 측정 예시이며, 웹에서 설정한 **200ms 명령 전송 주기**와도 다른 값이다.

## 남은 개선 과제

실제 구동에서는 미세한 모터 진동과 HTTP 통신 지연이 남았다. 후속 개선으로 제어 이득·필터 튜닝, 전송 주기 최적화, 기구 유격 감소와 각도 응답 로그 분석을 고려했다.
